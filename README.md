# Paper Trading prototype

An interactive copy of the TradingView chart page in Paper Trading mode, built as the base for a usability test of a redesigned order panel. It has live quotes, a chart, order execution, positions and P&L.

## Running

```bash
npm install
npm run dev        # http://localhost:5173, no keys needed (sim feed)
npm test           # unit tests: orderMath, deriveTicket, paperEngine
npm run build      # typecheck + production build
```

## URL flags

| Parameter | Values | Default | What it does |
|---|---|---|---|
| `?feed=` | `sim`, `binance`, `finnhub`, `live` | `sim` | Quote source (see below) |
| `?panel=` | `current`, `new` | `current` | Order panel variant. `current` is a copy of production; `new` is the redesign (step 2) |
| `?debug=1` | — | off | Hidden debug menu (bug button bottom-left): export the event log as JSON, fast-forward the clock to expire orders, drop live feeds, reset the account |
| `?theme=dark` | — | light | Dark theme (tokens only, not polished) |
| `?freeze=1` | — | off | Freezes sim prices (AAPL 201.56 / 201.57) for comparing against Figma |
| `?sandbox=1` | — | — | Gallery of the new panel's atoms in every state |
| `?sandbox=panel&panel=new&freeze=1` | `&h=799` | — | The panel alone at Figma frame size, for 1:1 screenshots |

The same settings can be set in `.env.local` (see `.env.example`): `VITE_FEED`, `VITE_PANEL`, `VITE_FINNHUB_KEY`. The URL takes priority over `.env`.

### Feeds

- **sim**: a random walk with ticks every 300–800 ms plus generated candle history. AAPL starts at Bid 201.56 / Ask 201.57. Needs no network and does not depend on market hours.
- **binance**: BTCUSDT and ETHUSDT come from the public Binance WebSocket (`bookTicker` → Bid/Ask, `aggTrade` → last) and REST `klines`. No key needed. Everything else runs on sim.
- **finnhub**: US stocks (AAPL, TSLA, NVDA, MSFT, AMZN) come from the Finnhub WebSocket. Requires `VITE_FINNHUB_KEY` in `.env.local`. Everything else runs on sim.
- **live**: every symbol uses its native feed. Forex always runs on sim.

If a live feed drops (socket error, no quotes for 12 s, failed history request, or no key), the symbol switches to sim starting from the last price, and a **Simulated data** badge appears in the header.

### Finnhub free tier limits

- WebSocket: `trade` prints only for US stocks, no Bid/Ask. Bid/Ask are derived from last with a 0.01 spread. Up to 50 symbols per connection.
- REST: 60 requests/min. `/quote` is free, but `/stock/candle` (history) is paid, so history is generated by the simulator and anchored to the current price from `/quote`. The previous close for the day change comes from `pc`.
- Outside the trading session there are no trades. After 12 s of silence the symbol switches to sim and shows the badge.

## Structure

```
src/
  config/        flags (URL/.env), symbol specs (tickSize, pointValue, currency, marginRate, leverage, minQty, qtyStep, assetClass)
  market/        MarketDataProvider + sim / binance / finnhub, routing and sim fallback (marketStore)
  lib/           orderMath.ts — pure calculations (value, margin, tick, SL/TP in every unit, size from risk, R:R); format.ts
  engine/        paperEngine.ts — paper trading engine with no UI dependency (orders, brackets, TIF, positions, account)
  order-ticket/  headless ticket model: TicketState → deriveTicket() → TicketView + OrderDraft; useOrderTicket()
  order-panel/   current/ — copy of the production panel; new/ — the redesign (2a: Market) with ui/ atoms,
                 presenters.ts (strings for the Figma tables) and Sandbox; index.tsx picks via ?panel=
  store/         uiStore (layout, symbol, ticket), tradingStore (engine + localStorage + toasts)
  analytics/     ticket event log for the usability test
  layout/        toolbars, chart, watchlist, bottom Paper Trading panel, toasts, debug menu
  styles/        tokens.css — every color and size token (light + dark), global.css
```

### Contract for the new panel (step 2)

A panel is just a view. It receives `ticket = useOrderTicket()`:

- `ticket.state`: raw input (side, type, price text, quantity and its unit, SL/TP, TIF);
- `ticket.view`: everything already computed (entry, offset from Ask/Bid in ticks, quantity in every unit, margin, tick value, real risk, SL/TP levels with money and percentages, R:R, expiry date, disabled-submit reason and its text, the finished `OrderDraft`);
- actions in `useTicketStore` (`setSide`, `setType`, `setQtyUnit`, `setExitUnit`, `submit` …): they write the events to the test log automatically.

Both panels submit the same `OrderDraft` to `paperEngine` through `tradingStore.placeOrder`.

## Ways to open the order panel

- **Sell / Buy** buttons in the top-left corner of the chart (opens with the matching side)
- **Shift+T**
- **Trade** button in the bottom Paper Trading panel or in the header
- Closed with the ✕ in the panel header (or Shift+T again)

## Event log (`?debug=1`)

Events: `ticket_open` (source, side), `ticket_close`, `side_change`, `type_change`, `unit_change`, `field_change` (written 700 ms after the last keystroke), `toggle_change`, `submit` (with `msFromOpen` — time from opening to submit), `submit_result`, `order_cancel`, `order_modify`, `position_close`, `symbol_change`. Each event carries the `panel` variant and a ticket `session` number. Export: Debug → Export events JSON.
